SAWIE Land Classifier — Complete API Reference

0. General Information

Base URL

Production / configured frontend client:
http://178.63.82.38:8001/api

Local development (default Uvicorn port):
http://127.0.0.1:8000/api

Interactive Swagger documentation:
http://<host>:<port>/docs

Authentication Header

Endpoints marked Auth require a JWT bearer token obtained from POST /api/auth/token. The frontend attaches it automatically:

Authorization: Bearer <access_token>

Common HTTP Status Codes

CodeMeaning in this API
200Success (read / update / delete)
201Created (successful POST creation)
400Bad request — invalid GeoJSON, duplicate key, wrong role value
401Missing, expired, or invalid JWT token
403Authenticated but not admin / deactivated account
404Field, scene, class, or label not found
Geometry convention: All GeoJSON in this API uses [longitude, latitude] order and is stored in PostGIS as SRID 4326 (WGS84).

1. Category: Authentication (/api/auth)

Manages users (labelers/admins) and JWT login tokens.

MethodEndpointAuthPurpose
POST/api/auth/tokenNoLogin, returns JWT
POST/api/auth/registerAdminCreate a new user

POST /api/auth/token

Purpose: Login. Validates email + password (bcrypt) and returns a JWT access token plus the user profile.

Input type: application/x-www-form-urlencoded (NOT JSON — OAuth2 password form).

Sample Input

username=admin@sawie.pk
password=SuperSecret123

Sample Output (200)

{
  "access_token": "eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9.eyJzdWIiOiIxIi...",
  "token_type": "bearer",
  "labeler": {
    "labeler_id": 1,
    "name": "Admin User",
    "email": "admin@sawie.pk",
    "role": "admin",
    "is_active": true
  }
}

Errors

400  { "detail": "Incorrect email or password" }
403  { "detail": "This account has been deactivated." }

POST /api/auth/register

Purpose: Create a new labeler or admin. Requires an admin token.

Sample Input (JSON)

{
  "name": "New Labeler",
  "email": "labeler2@sawie.pk",
  "password": "StrongPass123",
  "role": "labeler"
}

Sample Output (201)

{
  "labeler_id": 6,
  "name": "New Labeler",
  "email": "labeler2@sawie.pk",
  "role": "labeler",
  "is_active": true
}

Errors

400  { "detail": "Email is already registered." }
400  { "detail": "role must be 'labeler' or 'admin'." }
401  { "detail": "Could not validate credentials" }
403  { "detail": "This action requires admin privileges." }

3. Category: Agricultural Fields (/api/fields)

Creates and reads farmers, fields, and field boundary polygons (PostGIS POLYGON, SRID 4326).

MethodEndpointAuthPurpose
POST/api/fields/YesCreate farmer + field + polygon
GET/api/fields/NoList all fields (dropdown)
GET/api/fields/{field_id}NoGet one field + boundary
GET/api/fields/geojsonNoAll boundaries as FeatureCollection

POST /api/fields/

Purpose: Find-or-create the Farmer, create the Field, and store the boundary as an active FieldPolygonVersion (source = "Web Upload").

Sample Input

{
  "field_name": "North Block Sector A",
  "farmer_name": "Muhammad Ali",
  "boundary_geom": {
    "type": "Polygon",
    "coordinates": [
      [
        [72.0000, 31.0000],
        [72.0100, 31.0000],
        [72.0100, 31.0100],
        [72.0000, 31.0100],
        [72.0000, 31.0000]
      ]
    ]
  },
  "farmer_code": "Sawie-1001"
}

farmer_code is optional. If omitted and the farmer is new, a WEBCREATED-<timestamp> code is generated.

Sample Output (201)

{
  "field_id": 25,
  "field_name": "North Block Sector A",
  "farmer_name": "Muhammad Ali",
  "boundary_geom": {
    "type": "Polygon",
    "coordinates": [
      [
        [72.0000, 31.0000],
        [72.0100, 31.0000],
        [72.0100, 31.0100],
        [72.0000, 31.0100],
        [72.0000, 31.0000]
      ]
    ]
  }
}

Errors

400  { "detail": "Invalid GeoJSON geometry." }
400  { "detail": "Geometry parsing error: ..." }

4. Category: Imagery Management (/api/imagery)

Manual scene entry (legacy) plus the real Google Earth Engine / Sentinel-2 integration: best-scene selection, native CRS, true-color thumbnail, and the real 10 m pixel grid.

MethodEndpointAuthPurpose
POST/api/imagery/YesManual scene entry (legacy)
GET/api/imagery/field/{field_id}NoList scenes of a field
GET/api/imagery/field/{field_id}/sceneNoBest Sentinel-2 scene via Earth Engine
GET/api/imagery/field/{field_id}/pixel-gridNoReal Sentinel-2 pixel centers

POST /api/imagery/

Purpose: Manually attach an imagery scene to a field (backward-compatible workflow).

Sample Input

{
  "field_id": 25,
  "capture_date": "2025-06-15",
  "cloud_cover_pct": 1.5,
  "image_url": "https://server.arcgisonline.com/ArcGIS/rest/services/World_Imagery/MapServer/tile/{z}/{y}/{x}"
}

Sample Output (201)

{
  "scene_id": 42,
  "field_id": 25,
  "capture_date": "2025-06-15",
  "cloud_cover_pct": 1.5,
  "image_url": "https://server.arcgisonline.com/.../{z}/{y}/{x}"
}

Errors

404  { "detail": "Field not found." }

GET /api/imagery/field/{field_id}

Input: Path parameter, e.g. /api/imagery/field/25

Sample Output (200)

[
  {
    "scene_id": 42,
    "field_id": 25,
    "capture_date": "2025-06-15",
    "cloud_cover_pct": 1.5,
    "image_url": "https://earthengine.googleapis.com/v1/.../thumbnail"
  }
]

GET /api/imagery/field/{field_id}/scene

Purpose: Sends the field's active polygon to Earth Engine, searches COPERNICUS/S2_SR_HARMONIZED (2024-01-01 → 2026-12-31, cloud < 20%), picks the least-cloudy image, computes the native UTM CRS and a true-color thumbnail URL, and get-or-creates the ImageryScene row.

Sample Input

None — path parameter only: /api/imagery/field/25/scene

Sample Output (200)

{
  "field_id": 25,
  "scene_date": "2025-06-15",
  "cloud_pct": 1.23,
  "native_crs": "EPSG:32643",
  "thumb_url": "https://earthengine.googleapis.com/v1/projects/357562258612/.../thumbnail?...",
  "scene_id": 42
}

Errors

404  { "detail": "Field not found." }
404  { "detail": "No active polygon boundary for this field." }

GET /api/imagery/field/{field_id}/pixel-grid

Purpose: Returns the REAL Sentinel-2 pixel centers inside the field, computed with ee.Image.pixelLonLat() + batched reduceRegion() at native CRS and 10 m scale. Result is cached in ImageryScene.pixel_grid_cache.

Sample Input

None — path parameter only: /api/imagery/field/25/pixel-grid

Sample Output (200)

{
  "field_id": 25,
  "native_crs": "EPSG:32643",
  "scene_date": "2025-06-15",
  "scene_id": 42,
  "pixel_count": 3,
  "pixels": [
    { "pixel_id": 0, "lng": 72.00005, "lat": 31.00005 },
    { "pixel_id": 1, "lng": 72.00015, "lat": 31.00005 },
    { "pixel_id": 2, "lng": 72.00005, "lat": 31.00015 }
  ]
}

Errors

404  { "detail": "Field not found." }
404  { "detail": "No active polygon boundary for this field." }

5. Category: Pixel-Level Annotations (/api/labels)

Creates, reads, aggregates, and deletes pixel labels. Areas are computed with PostGIS ST_Area(ST_GeographyFromText(...)) in square meters and acres.

MethodEndpointAuthPurpose
POST/api/labels/YesCreate a pixel label
GET/api/labels/scene/{scene_id}NoAll labels of a scene
GET/api/labels/stats/field/{field_id}NoPer-class area statistics
DELETE/api/labels/{label_id}YesDelete a label

POST /api/labels/

Purpose: Save one labeled pixel. Validates scene + class existence and geometry validity, stores SRID=4326 geometry, and computes area.

Sample Input

{
  "field_id": 25,
  "scene_id": 42,
  "class_id": 1,
  "pixel_geom": {
    "type": "Polygon",
    "coordinates": [
      [
        [72.000005, 31.000005],
        [72.000095, 31.000005],
        [72.000095, 31.000095],
        [72.000005, 31.000095],
        [72.000005, 31.000005]
      ]
    ]
  },
  "notes": "Annotated via web interface"
}

Sample Output (201)

{
  "label_id": 101,
  "field_id": 25,
  "scene_id": 42,
  "class_id": 1,
  "class_key": "crop",
  "display_name": "Cultivated Crop",
  "hex_color": "#e6c619",
  "labeler_id": 1,
  "labeler_name": "Admin User",
  "pixel_geom": { "type": "Polygon", "coordinates": [ ... ] },
  "area_sq_meters": 98.74,
  "notes": "Annotated via web interface"
}

Errors

404  { "detail": "Scene ID 42 not found." }
404  { "detail": "LandCoverClass ID 1 not found." }
400  { "detail": "Invalid spatial geometry provided." }
400  { "detail": "GeoJSON parsing error: ..." }

Input: Path parameter, e.g. /api/labels/101
